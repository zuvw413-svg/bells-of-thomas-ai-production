# ملخص المشروع

## الفكرة

دراما تاريخية إنسانية تدور في دمشق خلال القرن السابع الميلادي، قبل الفتح الإسلامي. تستخدم الأجراس كعنصر سمعي ورمزي يربط بين الذاكرة والخوف والأمل، من دون اختزال المدينة في صراع واحد أو تقديم الشخصيات بوصفها رموزًا أحادية.

## الأهداف

- إنتاج موسم قصير متماسك بصريًا ودراميًا.
- بناء شخصيات خيالية داخل سياق تاريخي موثق.
- استخدام أدوات الذكاء الاصطناعي كمساعد إنتاج، مع مراجعة بشرية كاملة.
- تسليم نسخة قابلة للمونتاج والمراجعة والترجمة.

## قيود مهمة

- لا تُعرض الشخصيات أو الأحداث المتخيلة كحقائق تاريخية.
- تُراجع ا��أسماء والملابس والعمارة واللغة مع مستشار تاريخي.
- يُمنع تقليد أصوات أشخاص حقيقيين دون موافقة موثقة.
- لا تُستخدم صور أشخاص حقيقيين أو علامات تجارية أو مواد محمية بلا ترخيص.

## مخرجات الموسم

- 7 حلقات، كل حلقة 15 دقيقة تقريبًا.
- نسخة مشاهدة رئيسية 16:9، ونسخة ترجمة WebVTT.
- ملفات صوتية منفصلة للحوار والموسيقى والمؤثرات عند الإمكان.
- أرشيف للنسخ النهائية وبيانات الأصول.
