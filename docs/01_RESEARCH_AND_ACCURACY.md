# البحث والدقة التاريخية

## بروتوكول التحقق

لكل معلومة تاريخية مؤثرة في القصة، سجّل:

| الحقل | المطلوب |
|---|---|
| الادعاء | ما الذي تقوله القصة؟ |
| المصدر | كتاب/مقال/أرشيف/رابط |
| تاريخ الوصول | متى تمت المراجعة؟ |
| درجة الثقة | مؤكدة / مرجحة / غير محسومة |
| القرار الدرامي | إبقاء / تعديل / حذف |
| المراجع | اسم المسؤول عن التحقق |

## مجالات المراجعة

- جغرافيا دمشق وأسماء الأحياء والطرق في الفترة المقصودة.
- العمارة والأزياء والأدوات والعملات ووسائل النقل.
- اللغات واللهجات والمصطلحات الدينية والإدارية.
- العلاقات الاجتماعية والاقتصادية، مع تجنب إسقاط مفاهيم حديثة بلا تفسير.
- التواريخ السياسية والعسكرية وتسلسل الأحداث.

## سياسة عدم اليقين

عندما تختلف المصادر، لا يخفي السيناريو الخلاف. اختر صياغة درامية لا تدعي اليقين، وأضف ملاحظة في سجل البحث. يمنع توليد تفاصيل تاريخية من نموذج لغوي ثم اعتمادها بلا مصدر.
