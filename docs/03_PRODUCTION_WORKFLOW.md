# سير الإنتاج

## مراحل الحلقة

1. **تطوير:** logline، ملخص، بحث، معالجة.
2. **ما قبل الإنتاج:** سيناريو، storyboard، قائمة لقطات، مراجع الشخصيات.
3. **التوليد/التصوير:** توليد اللقطات أو تسجيلها مع حفظ الإصدارات.
4. **الصوت:** أداء، تنظيف، موسيقى، مؤثرات، مزج أولي.
5. **المونتاج:** assembly ثم rough cut ثم picture lock.
6. **المراجعة:** تاريخية، درامية، تقنية، وحقوق.
7. **التسليم:** master، نسخة مضغوطة، ترجمة، وأرشيف.

## بوابات الاعتماد

- **Gate A:** اعتماد الفكرة والبحث.
- **Gate B:** اعتماد السيناريو وقائمة اللقطات.
- **Gate C:** اعتماد الأصول والحقوق.
- **Gate D:** اعتماد rough cut.
- **Gate E:** picture lock وmix وQC.

## سجل الأصول

لا تنقل ملفًا إلى مرحلة لاحقة دون تسجيل: المعرّف، النوع، الحلقة/المشهد، المصدر، الأداة، الإصدار، المالك، الترخيص، الحالة، وملاحظات الاستمرارية.
