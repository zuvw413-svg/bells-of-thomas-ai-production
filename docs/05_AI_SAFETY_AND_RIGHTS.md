# الذكاء الاصطناعي والحقوق والسلامة

## قواعد إلزامية

- سجّل اسم الأداة، الحساب/الخطة، التاريخ، prompt، الإعدادات، والنتيجة.
- لا ترفع بيانات شخصية أو أصواتًا أو صورًا بلا موافقة.
- لا تقلّد فنانًا أو ممثلًا حيًا بالاسم أو الصوت دون ترخيص صريح.
- افحص شروط الاستخدام التجاري لكل أداة قبل النشر.
- راجع التشوهات البصرية، النصوص غير المقروءة، الوجوه، الأيدي، والرموز الدينية.
- ميّز المواد المولدة داخليًا عن المصادر الأرشيفية.

## الشفافية

احتفظ بسجل داخلي يوضح أين استُخدم الذكاء الاصطناعي. عند طلب منصة التوزيع الإفصاح عن ذلك، قدم وصفًا دقيقًا بدل ادعاء أن كل مادة صُورت تقليديًا.

## حفظ الأدلة

لكل أصل نهائي، احفظ prompt ومرجع الصورة ونسخة الأداة وقرار المراجعة. لا تعتمد على رابط مؤقت وحده.
