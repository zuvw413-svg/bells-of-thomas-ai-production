# قائمة فحص الإصدار

## القصة والدقة

- [ ] تمت مراجعة الحلقة تاريخيًا ولغويًا.
- [ ] لا توجد ادعاءات غير موثقة أو تم تمييزها بوضوح كخيال.
- [ ] تمت مراجعة الحساسية الثقافية والدينية.

## الصورة والصوت

- [ ] لا توجد لقطات مفقودة أو ملفات offline.
- [ ] الاستمرارية واللون مقبولان.
- [ ] الحوار مفهوم ولا يغطيه الموسيقى.
- [ ] الموسيقى والمؤثرات مرخصة.

## الترجمة والتقنية

- [ ] تم فحص WebVTT/SRT على النسخة النهائية.
- [ ] تم تشغيل الملف من بدايته إلى نهايته.
- [ ] تمت مراجعة مستوى الصوت ونقاط القطع.
- [ ] اسم الإصدار ورقم الحلقة صحيحان.
- [ ] تم حفظ checksum وموقع الأرشيف.

## التسليم

- [ ] Master محفوظ.
- [ ] نسخة مشاهدة محفوظة.
- [ ] Stems محفوظة.
- [ ] تم اعتماد النسخة من المنتج والمخرج ومسؤول الدقة.
